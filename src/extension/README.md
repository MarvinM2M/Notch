# WinNotch Web Connector Extension

Ekstensi Chrome ringan untuk meneruskan notifikasi dari **WhatsApp Web**, **Telegram Web**, dan **Discord Web** langsung ke WinNotch.

## Cara Pasang di Google Chrome / Microsoft Edge (15 Detik):
1. Buka browser Chrome, ketik `chrome://extensions` di address bar lalu Enter.
2. Di pojok kanan atas, aktifkan tombol **Mode pengembang (Developer mode)**.
3. Klik tombol **Muat yang belum dibongkar (Load unpacked)** di pojok kiri atas.
4. Pilih folder ini:
   `c:\Users\COMPUTER\OneDrive\Documents\notch\src\extension`
5. Selesai! Refresh tab WhatsApp Web / Telegram Web / Discord Web kamu.
   Setiap ada chat masuk, notch akan langsung memunculkan pop-up pesan secara instan!
